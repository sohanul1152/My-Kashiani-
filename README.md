🏡 My Kashiani — আমার কাশিয়ানী

কাশিয়ানীর পরিচয়, তথ্য ও সম্ভাবনার ডিজিটাল ঠিকানা।

My Kashiani একটি স্থানীয় তথ্যভিত্তিক ওয়েবসাইট, যার উদ্দেশ্য গোপালগঞ্জ জেলার কাশিয়ানী উপজেলার বিভিন্ন তথ্য এক জায়গায় তুলে ধরা।

🌍 ওয়েবসাইট সম্পর্কে

এই ওয়েবসাইটে ধীরে ধীরে কাশিয়ানী উপজেলার বিভিন্ন এলাকার তথ্য যুক্ত করা হবে, যাতে স্থানীয় মানুষ ও দূরের মানুষ সহজেই কাশিয়ানী সম্পর্কে জানতে পারেন।

🎯 আমাদের লক্ষ্য

কাশিয়ানী উপজেলার তথ্য সহজলভ্য করা, স্থানীয় পরিচিতি তুলে ধরা এবং একটি সুন্দর ডিজিটাল কমিউনিটি গড়ে তোলা।

🛠️ ব্যবহৃত প্রযুক্তি

- HTML
- CSS
- JavaScript
- GitHub
- GitHub Pages

🚀 ওয়েবসাইট চালু করার পদ্ধতি

এই প্রজেক্টটি GitHub Pages ব্যবহার করে বিনা খরচে হোস্ট করা যাবে।

1. Repository-তে "index.html" ফাইল রাখুন।
2. GitHub Repository-র Settings → Pages খুলুন।
3. Source হিসেবে "Deploy from a branch" নির্বাচন করুন।
4. Branch হিসেবে "main" এবং Folder হিসেবে "/(root)" নির্বাচন করে Save করুন।
